HanziFlow · Browser Extension

A fine-tuned small language model that segments Chinese text in real time inside the browser, replacing paid NLP APIs.

Team project · my roleFine-tuned and evaluated the model, and co-designed the architecture that serves it to the browser extension.

Firefox extension → FastAPI → Haystack RAG + Unsloth SLM

  • Qwen3-8B
  • QLoRA
  • Unsloth
  • FastAPI
  • Haystack
Problem
Third-party NLP APIs are costly, slow and hard to customise for high-volume text segmentation. Tools like Jieba mis-segment domain-specific text.
Approach
Compared 4 open models, then fine-tuned Qwen3-8B with QLoRA (Unsloth) on 17.6k Chinese Treebank sentences, checked it against Jieba and ChatGPT, and served it through FastAPI with a Haystack RAG layer to a Firefox extension.
Result
Comparable to Jieba in a human-reviewed comparison, with no paid API needed, deployed as a working browser extension.

HanziFlow · Learning App

A Flutter app that takes absolute beginners through HSK 1 Chinese, with AI feedback on pronunciation and handwriting, and AI-generated practice sentences.

Team of 3 · my roleBuilt the Flutter app (Android and web), connected to Supabase and the AI services, and contributed to building the pronunciation model.

Problem
Beginner apps rarely give honest feedback: speech recognition auto-corrects wrong tones, writing isn't checked, and vocabulary is memorised without context.
Approach
A Flutter app (Android and web) backed by Supabase, calling a FastAPI server on AWS EC2 with three AI services: Wav2Vec2 (XLSR-53) with separate initial, final and tone CTC heads for pronunciation scoring, a ResNet CNN that compares handwriting with 256 character templates, and DeepSeek sentence generation that is validated against the HSK 1 word list, with retries and a template fallback.
Result
Live at hanziflow.site · Strict by design: 0 wrong pronunciations accepted in a 100-clip AISHELL test, and 0 of 946 unknown inputs accepted in an 11,600-sample CASIA handwriting test. User testing with beginners is next.
